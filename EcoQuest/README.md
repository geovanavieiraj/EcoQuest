# EcoQuest - A Missão do Planeta

Jogo educativo de conscientização ambiental desenvolvido em Python com Pygame.

## Como executar

1. Instale Python 3.
2. Abra esta pasta no VS Code.
3. No terminal, execute:
   pip install -r requirements.txt
4. Depois:
   python main.py

## Controles
- Setas ou A/D: movimentar
- Espaço: pular
- ESC: sair

O jogo possui cinco fases:
1. Floresta
2. Rio
3. Cidade
4. Energia
5. Planeta

O objetivo é coletar itens recicláveis, evitar obstáculos e responder perguntas ambientais.
